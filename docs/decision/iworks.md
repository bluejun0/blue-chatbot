# iWorks 챗봇

blue-iWorks 사내 포털 이용자를 위한 챗봇. 아직 구현되지 않은 결정을 적는다.

## 온보딩

- 위젯을 열면 인사말과 카드 2장을 먼저 보여준다. `정보 안내`와 `문의` 두 장이다.
- 카드에는 누르면 사용자 메시지로 전송될 문구를 미리 넣어둔다. 카드는 화면 장식이 아니라 미리 써둔 사용자 대사다.
- `문의` 카드는 노출하되 동작은 구현하지 않는다.

## 정보 안내

- RAG로 구현한다. 지식원 전체를 프롬프트에 넣지 않고, 질문과 관련 있는 부분만 찾아 근거로 쓴다.
- 지식원은 기존 FAQ와 포털 문서 양쪽을 포함한다. FAQ 형식이 아닌 문서도 넣는다.
- RAG를 택한 이유는 두 가지다. FAQ가 크게 늘어날 예정이라 전부 프롬프트에 넣는 현재 방식이 유지되지 않고, FAQ 형식이 아닌 문서를 넣을 자리가 필요하다.

## 벡터 저장소

- Qdrant를 쓴다.
- 기존에 쓰는 DB가 벡터 검색을 지원하지 않아 별도 저장소가 필요하다.

## 대화

- 여러 턴에 걸친 대화를 유지한다.
- 답변은 SSE로 스트리밍한다.
